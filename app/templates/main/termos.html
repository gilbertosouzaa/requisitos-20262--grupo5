Termos de Uso

1. Finalidade do Projeto

O Apoio ENADE é um sistema com finalidade exclusivamente acadêmica e educativa, desenvolvido para auxiliar estudantes na preparação para o Exame Nacional de Desempenho dos Estudantes (ENADE).

2. Conteúdo das Questões

O banco de questões baseia-se em edições públicas anteriores divulgadas pelo INEP/MEC. Os textos de apoio e questões fictícias criados para prototipagem são de cunho demonstrativo.

3. Responsabilidades

O usuário compromete-se a utilizar a plataforma para fins legítimos de estudo e revisão pedagógica.
